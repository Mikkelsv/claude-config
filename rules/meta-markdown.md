# Markdown Rules

All `.md` files must pass markdownlint without warnings:

- **MD022**: Blank line required above and below every heading
- **MD031**: Blank line required around fenced code blocks
- **MD032**: Blank line required above and below every list
- **MD040**: Fenced code blocks should have a language specified
- **MD060**: Tables use compact style. Every pipe `|` must have a space on both sides — including in the separator row. Correct: `| --- | --- |`. Wrong: `|---|---|`.
